# 《红色派系》(2001) 标牌贴图汉化 — 文字对照表

共 193 张场景标牌/海报贴图，其中 183 张需要把英文改成中文，10 张只有企业标志或箭头、不用动。

## 改图要求

1. **尺寸必须和原图完全一致**，一个像素都不能差。
2. **必须保留透明通道**。这批图里绝大多数是靠 alpha 抠出字形/形状的贴花，
   压成不透明的方块会在游戏里变成一块难看的矩形。
3. **只替换文字，其余一律不动**：底板、锈迹、划痕、条形码、红色小字装饰条、
   ULTOR 齿轮标志、编号数字，全部原样保留。
4. **沿用原字体的气质**：多数是工业风无衬线体（类似 Eurostile / DIN），
   涂鸦类是手写体。中文请选对应风格的黑体或手写体，并复刻原有的
   浮雕、描边、做旧、磨损效果。
5. **保持原有的行数与排版**。下表 `中文` 一列里的 `/` 表示换行位置。
6. 存成 **PNG（带 alpha）或 TGA 均可**，文件名保持不变。
